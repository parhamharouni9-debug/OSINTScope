OSINTScope’s first public release supports Python 3.11+ and is available under the MIT license.

- Investigate domain registration, historical DNS, routing origins, certificate transparency, and archived HTTP technology metadata through five public sources.
- Save timestamped observations and their source references in SQLite. Compare investigations with coverage information to distinguish newly observed records from gaps in the evidence.
- Export investigations as standalone HTML reports or machine-readable JSON, including the evidence supporting observed and inferred relationships.

After installation, run `osintscope sources` to see the providers or `osintscope scan example.com` to start an investigation.
